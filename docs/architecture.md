# 匹配原理与实现

AvatarCompare 先检查文件内容和解码像素，再寻找候选图与目标图之间的局部几何对应。报告按证据类别显示结果，可同时查看结构相似度和局部对应点。

## 证据怎么读

- **文件完全相同**表示原始字节一致。
- **像素完全相同**表示解码、校正方向和透明背景处理后像素一致。
- **局部位置关系一致**表示 SIFT 匹配点通过 RANSAC 单应矩阵验证，并满足当前的内点与覆盖要求。请在报告中核对两张图及其对应点。
- **证据不足**可能来自低分辨率、缺少纹理、裁剪或遮挡。同一张图片也可能被多个账号使用，报告仅描述图像之间的证据。

全局哈希用于辅助排序和诊断。裁剪会显著改变全局特征，因此匹配仍会检查局部几何。低分辨率、重复纹理和复杂变换均可能造成误报或漏报。

## 代码入口

- [`__main__.py`](../avatar_compare/__main__.py)选择本地或范围任务并生成报告。
- [`gui.py`](../avatar_compare/gui.py)提供本机服务，静态页面位于 [`web/`](../avatar_compare/web/)。
- [`engine.py`](../avatar_compare/engine.py)处理本地文件夹，范围模式由 [`range_engine.py`](../avatar_compare/range_engine.py) 和 [`staged.py`](../avatar_compare/staged.py)实现。
- [`features.py`](../avatar_compare/features.py)实现图像特征和匹配证据，[`report.py`](../avatar_compare/report.py)生成复核报告。

结果与恢复状态通过 SQLite 持久化。范围模式支持有界下载、计算和写入，并复用图片特征。处理规模仍受服务端吞吐、磁盘容量和网络状况影响。

现有回归使用合成图片和本机接口验证恢复、失败重试、导出和图形界面；匹配阈值尚未在大规模真实图库上校准。运行方式见[贡献指南](../CONTRIBUTING.md#运行测试)。
